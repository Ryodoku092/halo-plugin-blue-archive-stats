浏览器打开 bilibili.com → F12 → Application → Cookies
复制 SESSDATA 和 bili_jct 的值，格式: SESSDATA=值1; bili_jct=值2

📋 页面预览

📖 使用说明

1. 配置步骤：

  • 填写 B站 UID 和 Cookie
  • 点击「保存配置」
  • 点击「立即刷新数据」获取第一次数据

2. 在博客中展示：

在 Halo 文章/页面中插入：

<iframe src="/apis/console.api.blue-archive.halo.run/v1alpha1/stats/html" 
        width="100%" height="1200" 
        style="border:none;" loading="lazy"></iframe>

3. Cookie 有效期：约 1-3 个月，过期后重新获取即可。

4. 签名 URL：每次自动重新生成，永不过期。
